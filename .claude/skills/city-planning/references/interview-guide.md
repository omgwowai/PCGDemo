# 需求访谈指南

目标：用最少的问答轮次把"我想要一座城"收敛成可量化的规划参数。
用 AskUserQuestion 工具（每轮 ≤4 题）。第一轮问大方向，第二轮补细节。
用户选"Other"或答非所选时，跟进一条自由文本澄清即可，不要反复追问。

## 第一轮 — 大方向（4 题）

**Q1 规模** (header: 规模)
- 小镇 ~1.5km²（步行尺度，几百栋建筑）
- 中型城区 ~5km²（推荐默认；对应半径 ~1.2km）
- 大城市 ~20km²（需要 World Partition/分区生成，成本高，提醒用户）

**Q2 路网结构** (header: 路网)
- 方格网（曼哈顿式，PCG 实现最稳，推荐默认）
- 放射环形（巴黎式，中心广场向外辐射）
- 有机混合（老城风格，主干道 + 不规则支路；PCG 里用噪声扰动网格近似）

**Q3 城市结构** (header: 结构)
- 单中心（CBD 高楼在中心，密度向外递减——inZOI/美式典型）
- 双中心（商业中心 + 行政/文化中心）
- 多组团（几个独立邻里，各有小中心）

**Q4 风格基调** (header: 风格)
- 现代都市（玻璃楼 + 规整街区）
- 欧洲小镇（坡顶房 + 广场 + 教堂）
- 亚洲混合（高密度住宅 + 底商 + 小巷）

## 第二轮 — 细节（按第一轮答案裁剪，≤4 题）

**Q5 分区比例** (header: 分区)
按风格给 2-3 组预设比例让用户挑，例如单中心现代都市：
- 商业 15% / 住宅 55% / 绿地 20% / 公共 10%（宜居，推荐）
- 商业 30% / 住宅 40% / 绿地 15% / 公共 15%（CBD 强）
- 自定义（追问一条自由文本）

**Q6 公共配套** (header: 配套, multiSelect: true)
- 教育（学校/幼儿园）
- 医疗（医院/诊所）
- 文体（体育场/图书馆/广场）
- 交通（公交站/停车场/地铁站口）
选中的进清单；数量按规模自动配比（如每 2km² 一所学校），在规划文档里列明。

**Q7 街道家具丰富度** (header: 街道)
- 基础（路灯 + 行道树）
- 标准（+ 长椅/垃圾桶/公交亭，推荐）
- 丰富（+ 消防栓/邮筒/护栏/斑马线，实现成本↑）

**Q8 展示方式** (header: 展示)
- 图内开关，两种模式随时切（推荐，成本几乎为零）
- 仅 debug 点（快速迭代阶段）
- 仅真实 mesh

## 答案 → 参数的换算规则

- 占地边长 L = sqrt(面积)；TOWN_EXT = L/2（UE 单位 cm，1km = 100000）
  - 注意：本项目模板里 12000 = 240m 半径，属于"迷你镇"。用户要 1.5km² 时 TOWN_EXT ≈ 61000，
    需同步放大 BLOCK（街区间距，城市 6000-10000，小镇 3000-5000）
- 密度梯度：单中心 → 用"到中心距离"的 DensityFilter 阈值切环；商业占比 x% → 中心圈半径 ≈ sqrt(x%) × TOWN_EXT
- 建筑量级预估：住宅数 ≈ 住宅区面积 / 宅地面积(约 500m²)，写进规划文档让用户有预期
- 每项配套换算成"每 N 街区 1 个"或"固定 K 个"，写进 city_plan.json 的 facilities 数组
